## Перевірка production-версії після налаштування GitHub Pages

- Production-збірка відкривається за base-шляхом `http://localhost:4174/TypeScript/Cyber-Detective/`, що відповідає очікуваній адресі GitHub Pages для репозиторію `TypeScript` і підпапки `Cyber-Detective`.
- Візуально головна сторінка завантажується коректно: відображаються навігація, блоки статистики, архів справ і оновлений адаптивний дизайн.
- Маршрутизація працює через hash-посилання (`#/...`), тому переходи не потребують серверних rewrite-правил і мають стабільно працювати на GitHub Pages.
- Перехід до навчальної справи відкрив сторінку `#/case/tutorial-01`, де відображаються вкладки брифінгу, підозрюваних, доказів, листування, дошки, терміналу та звинувачення.
