# Cyber Detective — Detective Noir Redesign + INVESTIGATION BOARD v2

Ця версія є експериментальною, але вже повноцінно інтегрованою реалізацією детективного редизайну для проєкту `cyber-detective-enhanced`. Основний акцент зроблено на атмосфері кімнати розслідувань: темний cinematic noir layout, фонові зображення дошки доказів, dossier-картки, плівкова віньєтка, ефекти папок, ниток, evidence board та нова інтерактивна вкладка `Дошка` у статичних справах.

## Що реалізовано

| Напрям | Реалізація |
|---|---|
| Візуальна атмосфера | Додано темний detective/noir стиль, hero із фоном дошки розслідування, glow-ефекти, dossier-панелі, case folders і полароід-картки. |
| Assets | Згенеровані concept-зображення додано в `client/public/redesign/` і `client/public/tools/`; вони використовуються як атмосферні фони та preview-зображення. |
| Головна сторінка | `Home.tsx` переписано у форматі cinematic landing page з описом нового investigation workflow, архівом справ і блоком про вкладку `Дошка`. |
| Архів справ | `CasesPage.tsx` оновлено під стиль детективних досьє з operation badges, складністю, винагородою та темною візуальною подачею. |
| Сторінка справи | `CasePage.tsx` отримала нову noir-оболонку, hero-фон, посилення шапки, progress display і вкладку `Дошка`. |
| INVESTIGATION BOARD v2 | `EvidenceGraph.tsx` переписано як персональне робоче полотно детектива з кінематографічним фоном, режимами `Move`, `Connect`, `Sticky`, `Card`, `Photo`, `Theory`, фільтрами, inspector-панеллю, auto layout і clear custom. |
| Власні елементи | Користувач може додавати власні sticky notes, картки, фото/скриншоти та гіпотези прямо на дошку, редагувати їх у правій панелі й видаляти власні елементи. |
| Нитки між елементами | У режимі `Connect` можна вибрати два елементи та створити між ними нитку з типом зв’язку і підписом. Візуальна перевірка підтвердила зміну лічильника `Links` з `0` на `1`. |
| Локальне збереження | Стан дошки зберігається через `localStorage` окремо для кожної справи, тому власна логіка розслідування не зникає після перезавантаження сторінки. |
| Глобальні стилі | В `client/src/index.css` додано CSS-класи для noir-shell, detective-board, dossier-panel, evidence-card, tape/ribbon accents і плівкової атмосфери. |

## Перевірка

Після інтеграції виконано фінальну перевірку:

```bash
npm run check
npm run build
```

Обидві команди завершились успішно. Під час production-збірки залишаються попередження Vite про `%VITE_ANALYTICS_ENDPOINT%` і `%VITE_ANALYTICS_WEBSITE_ID%` у `client/index.html`; вони не повʼязані з редизайном і не блокують збірку.

Окремо вручну перевірено вкладку `/case/case_404` → `Дошка`: створення sticky note, відкриття inspector-панелі, роботу режиму `Connect` і появу видимої нитки між власною нотаткою та доказом справи.

## Як запустити

```bash
npm install
npm run dev
```

Після запуску відкрийте локальну адресу, яку покаже Vite, зазвичай `http://localhost:3000/`.

## Що подивитися в першу чергу

| Маршрут | Що перевірити |
|---|---|
| `/` | Новий detective hero, cinematic noir атмосфера та загальна подача гри як цифрового розслідування. |
| `/cases` | Архів справ у стилі детективних досьє. |
| `/case/case_404` | Нову шапку справи, вкладки й інтеграцію noir-оболонки. |
| `/case/case_404` → `Дошка` | Персональну INVESTIGATION BOARD v2: додавання нотаток, карток, фото, гіпотез, переміщення вузлів і з’єднання елементів нитками. |

## Подальші ідеї

Поточна версія вже реалізує головну вимогу — персональну детективну дошку поверх автоматично підтягнутих доказів справи. Наступним етапом можна поглибити механіку: додати drag-and-drop локальних фото, експорт дошки у зображення, undo/redo, шаблони гіпотез, дедуктивні оцінки зв’язків і можливість синхронізувати дошку між пристроями.
